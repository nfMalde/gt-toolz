# Corner names

`corner-names.json` is derived from the same repository and commit as the track signatures
(`packages/telemetry/data/SOURCE.md`): for every surveyed configuration with
corner data, the turn number, name and apex position (x/z) of each corner. Extracted from `tracks/*.json`
(26 bundles, 10 of them with corner data: 139 corners, 32 with a name).
