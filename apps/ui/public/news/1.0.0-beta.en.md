## Beta release

GT Toolz is available now: unofficially, as a beta. It is a hobby project and still a work in progress.

- **Windows** is fully tested.
- **macOS and Linux** are only half tested. Errors or crashes can still happen there.
- **German voices** can be hard to understand at times. That is on the list for the next release.

### Found a bug?

Switch on the **Detailed log** under **Settings → Diagnostics**, drive the spot once more, then save the **Log for a GitHub issue**. **About & licenses → Report a bug** takes you to the bug report on GitHub; attach the file there.

Thanks for testing!
